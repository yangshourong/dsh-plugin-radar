# dsh-plugin-radar 开发计划

> 原则：小步快跑，每一步都带测试与验证。状态：`todo` / `in-progress` / `done` / `blocked`。
> 当前基线：`0.1.3`（配置页 + GitHub Token 已上线）；本计划从 `0.2.0` 开始。

## 里程碑

| 版本 | 主题 | 目标 |
|---|---|---|
| `0.2.0` | 配置体验 | 配置立即生效、Token 状态可见且可校验 |
| `0.2.x` | 安装闭环 | 结果卡片一键安装、已安装状态 |
| `0.3.0` | 图形化发现 | Plugins 页"插件雷达"tab（搜索/分类/安装） |
| `0.3.x` | 安全与分发 | Token 入凭据库、结果可信信息、发布自动化 |

## 0.2.0 细化（本次）

- [x] Host 侧把配置读取改为按调用/按请求读取（volatile 盒子实时值）
- [x] Token 状态接口 `GET /dsh-plugin-radar/status`（实测：configured=true、source=settings、不泄露 token）
- [x] Token 校验接口 `POST /dsh-plugin-radar/token/validate`（实测：真实 token → 30 次/分；坏 token → 401 无效）
- [x] 配置页显示已配置/未配置、验证按钮、检查当前额度
- [x] 单测：配置热更新、token 校验、HTTP 处理器（49 个用例全绿）
- [ ] 页面手动验证：Token 状态徽标、验证按钮、改设置后立即生效
- [ ] 发布 0.2.0（npm + tag + Release）
